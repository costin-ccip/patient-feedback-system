# Patient Feedback Collection System

Spec-driven build of Cape Clarity's centralized patient feedback pipeline,
built with [GitHub Spec Kit](https://github.com/github/spec-kit).

- `.specify/memory/constitution.md` — project principles (de-identification,
  compliance verification, automated triggers, etc.)
- `specs/001-feedback-collection-pipeline/spec.md` — the current feature spec
- `specs/001-feedback-collection-pipeline/checklists/` — spec quality checklist
- Source design doc: [Feedback Collection — Proposed Tech Stack](https://icostin.atlassian.net/wiki/spaces/LP/pages/565313537/Feedback+Collection+Proposed+Tech+Stack)

Workflow: constitution → specify → clarify → plan → tasks → implement, each
step reviewed before moving to the next.
